# 🚀 快速开始 · Quick Start

# **第 1 步**:将技能目录放入智能体的用户级技能目录:

# ```bash
Linux / macOS
# mkdir -p ~/.workbuddy/skills
# cp -r skills/bendi-vido ~/.workbuddy/skills/

Windows
将 skills/ 下技能复制到 C:\Users\<你的用户名>\.workbuddy\skills\
# ```

# **第 2 步**:在对话中调用技能:

# ```
# /bendi-vido               # 一键成片全流程
# /auto-drama-writing       # 短剧自动定时写作
# ```

# 每个技能均自带完整流程指令,详见各技能目录内 `SKILL.md`。
