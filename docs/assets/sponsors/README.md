# 赞助商展示位 · Sponsors

仓库顶部 README 与官网首页均设有**赞助商展示位**,感谢各位伙伴支持开源项目持续更新。

## 展示位权益

| 档位 | 展示位置 | 说明 |
|------|---------|------|
| 🥇 首席赞助 | README 顶部首位 + 官网首页首位 | Logo + 链接 + 一句话介绍 |
| 🥈 联合赞助 | README 顶部第二位 | Logo + 链接 |
| 🥉 支持赞助 | README 顶部第三位 | Logo |

## 如何投放

1. 联系微信(见仓库 README"联系我")洽谈档位;
2. 提供 Logo(建议 PNG,透明底,≥512px);
3. 投放后即展示于仓库顶部。

## 文件说明

将赞助商 Logo 放在本目录 `docs/assets/sponsors/` 下,命名 `sponsor_<档位>_<名称>.png`,并在 README 赞助商区块中引用(`docs/assets/sponsors/<文件名>`)。
