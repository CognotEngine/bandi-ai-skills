# 技能开发规范 · Skill Development Guide

本目录收纳班迪 AI 技能库的全部技能。**每个技能 = 一个自包含目录**,可独立分发、独立安装。

## 目录结构(硬性规范)

```
skills/<技能名>/
├── SKILL.md                  ← 主指令(必填):流程主控 + 触发条件
├── references/               ← 参考资料(可选):模板库 / 方法论
│   └── *.md
└── scripts/                  ← 脚本增强(可选):批量处理 / 工具脚本
    └── *.py
```

## SKILL.md 编写要点

| 模块 | 要求 |
|------|------|
| 头部说明 | 技能名、用途、触发条件、运行说明 |
| 流程 | 分阶段推进,每阶段有 📢 进度报告 + ⏸ 确认点 |
| 模板 | 提示词模板统一放 `references/`,主文件引用 |
| 可移植性 | 纯文本指令优先,不绑定平台/API/授权码 |
| 决策点 | 需要用户拍板处,明确列出可选项(禁止直接跑) |

## 命名约定

- 目录名:小写 + 连字符,如 `bendi-vido`;
- 图片资产:按用途分类存放(`assets/` 下一级),如 `assets/场景/场景_01_楼道口.png`;
- 文件命名:`类型_序号_名称`,统一可排序。

## 发布检查清单

- [ ] SKILL.md 流程可完整通读,无缺步骤
- [ ] 提示词模板与主文件引用一致
- [ ] 脚本零依赖或标注依赖
- [ ] 无平台锁定、无版权风险素材
- [ ] README 技能列表已登记
