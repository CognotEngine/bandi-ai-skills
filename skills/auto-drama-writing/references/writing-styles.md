# 14种写作风格指令

写作风格指令会注入到所有生成函数的上下文中，影响大纲生成、剧集写作、专家评审的基调。选择风格时参考下表，用户未指定时按项目类型用默认值（script→`hollywood`，novel→`web_xianxia`）。

## 剧本类风格（7种）

### hollywood — 好莱坞商业片（默认）
```
【写作风格：好莱坞商业片】
- 遵循经典三幕式结构，注重情感stakes
- 每场戏都要有存在价值，不写无意义的场景
- 台词要能展现人物性格，避免直白说教
- 场景结尾留有钩子，推动观众继续观看
- 注重人物弧光，主角要有清晰的成长/转变
```

### classical — 古典叙事
```
【写作风格：古典叙事】
- 运用神话原型和经典叙事模式
- 注重主题的贯穿性，每个场景都服务于主题
- 采用英雄之旅结构，注重仪式感和象征意义
- 戏剧张力循序渐进，注重命运的不可抗拒
- 平衡壮阔场面与深刻内涵
```

### hero — 英雄之旅
```
【写作风格：英雄之旅】
- 严格遵循坎贝尔的单神话结构
- 主角要有清晰的"历险召唤→拒绝→接受"过程
- 设计导师角色，给予关键指引和道具
- 每个考验都要揭示主角的新特质
- 包含象征性的死亡与重生，主角在精神层面完成蜕变
```

### nolan — 诺兰式复杂叙事
```
【写作风格：诺兰式复杂叙事】
- 采用非线性叙事，打乱时间线制造悬念
- 早期埋下伏笔，后期揭示，奖励细心观众
- 在复杂结构下保持情感内核，让观众关心人物
- 可使用不可靠叙述者，增加解读层次
- 结尾要有主题回响，留下思考空间
```

### comedy — 喜剧
```
【写作风格：喜剧】
- 幽默来自人物性格，而非单纯堆砌笑话
- 注重setup和punchline的节奏
- 夸张人物特质制造喜剧冲突
- 喜剧中要有真情实感，笑中带泪
- 设计"直人"角色，与搞笑角色形成反差
```

### horror — 恐怖
```
【写作风格：恐怖】
- 以慢热张力为主，而非单纯jump scare
- 恐惧来源于未知，留白让观众想象
- 先让观众关心角色，再让他们陷入危险
- 逐步建立不安氛围，而非一惊一乍
- 适度颠覆预期，给观众意想不到的惊吓
```

### sci-fi — 科幻
```
【写作风格：科幻】
- 早期建立世界观规则，后续保持一致
- 技术服务于故事，而非炫技
- 探讨科技对人性和社会的深层影响
- 即便最奇幻的设定也要有逻辑支撑
- 平衡硬科幻的逻辑性与软科幻的思想性
```

## 小说类风格（7种）

### classic_literature — 经典文学
```
【写作风格：经典文学】
- 注重语言的文学性和艺术性，用词精准有韵味
- 深入刻画人物内心世界和心理活动
- 主题宏大深刻，探讨人性、命运、社会等永恒命题
- 结构严谨，叙事节奏从容不迫
- 多用象征、隐喻等文学手法，富有思想深度
- 人物塑造立体复杂，不是非黑即白
```

### modernist — 现代派
```
【写作风格：现代派】
- 打破传统线性叙事，采用意识流、内心独白等手法
- 深入探索人物潜意识和精神世界
- 时间概念模糊，过去现在未来交织
- 语言实验性强，句式多变，不循常规
- 关注异化、孤独、存在主义等现代性主题
- 叙事视角多元，常使用不可靠叙述者
```

### web_xianxia — 网络爽文（默认）
```
【写作风格：网络爽文】
- 节奏快，冲突密集，每章都要有爽点
- 主角光环明显，升级打怪清晰有层次
- 打脸反派要干脆利落，让读者出气
- 设定体系清晰（修为/等级/功法），方便读者代入
- 多用悬念和钩子，章末留悬念让人想看下一章
- 人物标签鲜明，配角各有特色，不脸谱化但辨识度高
- 金手指设定合理，有成长空间，不无敌得太早
```

### mystery — 悬疑推理
```
【写作风格：悬疑推理】
- 早期埋线索，设悬念，制造谜团
- 节奏张弛有度，紧张与舒缓交替
- 逻辑严密，伏笔回收完整，结局合理且出人意料
- 营造悬疑氛围，调动读者好奇心和探究欲
- 人物动机清晰，行为符合逻辑
- 反转要有铺垫，不强行反转，不为反转而反转
- 注重心理描写和气氛渲染，用文字制造紧张感
```

### sci_fi_fantasy — 科幻奇幻
```
【写作风格：科幻奇幻】
- 世界观设定宏大完整，体系自洽有逻辑
- 早期铺设定但不堆砌，通过剧情自然展现
- 核心设定有创新性，不照搬现有模板
- 硬科幻要讲科学逻辑，奇幻要有魔法/修炼体系规则
- 探讨科技/魔法对人性和社会的影响
- 用想象力冲击读者，但情感内核要真实
- 细节描写到位，让世界有质感有温度
```

### romance_healing — 言情治愈
```
【写作风格：言情治愈】
- 情感细腻真实，不矫情不做作
- 男女主互动有化学反应，感情发展自然不突兀
- 甜宠有度，不油腻，有糖也有刀
- 人物性格鲜明，CP感强，有反差萌更好
- 注重心理描写，展现人物内心的柔软和成长
- 治愈感来自人物的互相救赎和共同成长
- 日常细节温暖动人，小情节也能打动人心
```

### hot_blooded — 热血战斗
```
【写作风格：热血战斗】
- 战斗场面有画面感，招式清晰，节奏明快
- 主角有坚定信念，战斗有理由，不为打而打
- 升级/突破有铺垫，燃点到来时读者热血沸腾
- 同伴情谊深厚，团队战比个人战更有冲击力
- 反派有魅力，有自己的信念，不是纯粹的坏
- 战斗不仅是力量比拼，也是意志和智慧的较量
- 节奏紧凑，高潮迭起，让人看得心跳加速
```
