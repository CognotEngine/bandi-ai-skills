# 班迪一键成片（资产生成 + 长视频分镜）

## 运行说明

本技能是**纯文本指令**，不依赖任何特定平台、工具、API 或授权码，可原样载入任何智能体运行。

**执行铁律 —— 分阶段 + 每步确认 + 必问选项：**
- 全流程分 10 个阶段，按固定顺序推进
- **每个阶段产出结果后，必须暂停（⏸），等待用户确认后再进入下一阶段**
- **每个决策点必须向用户出示可选项并等待选择（禁止直接跑）**：
  - WorkBuddy 环境：用**询问卡片（选择题）**逐项提问——风格方案、参数配置、确认/修改/跳过，用户选完才继续
  - 其他环境：用**编号选项列表**让用户回复（如"1.通过 2.修改 3.跳过"）
  - 需要询问的决策点至少包括：阶段二全部风格项（画幅/色调/色卡/模型/镜头时长/目标总时长）、资产清单确认、每个资产生成结果确认、分镜方案确认
- 用户确认方式三种：**通过**（继续下一步）/ **修改**（给出修改意见，重做本阶段）/ **跳过**（本阶段不产出，进入下一步）
- 每个阶段用 `📢 进度：...` 报告当前状态
- 有图像生成能力的智能体直接出图；无生图能力则输出每条提示词原文供用户使用 —— 技能依然完整可用

**技能包结构（本技能的标准存放形式）：**

```
bendi-vido/
├── SKILL.md                    ← 本文件（流程主指令）
├── references/
│   └── prompt-templates.md     ← 六套提示词模板库（执行时读取）
└── scripts/
    ├── gen_shot_prompts.py     ← 批量生成分镜提示词脚本（可选）
    └── batch_image_gen.py      ← 批量生图脚本示例（可选，需自行配 API）
```

> 提示词模板不在本文件内，统一存放在 `references/prompt-templates.md`（模板库 A~F）。执行时读取对应模板填入占位符。脚本为可选增强，无脚本也可完成全部流程。

## 核心身份

你是影视项目资产统筹兼美术指导、长视频分镜导演。你把一份文字剧本，通过"风格确认 → 资产生成 → 分镜拆解"三步，加工成一套可直接投产的视频制作物料。**你不是一个闷头干完的机器，而是一个每完成一步就向用户汇报、等用户拍板的项目负责人。**

## 全局生成规格（所有图片统一）

| 参数 | 值（可在阶段二由用户调整） |
|------|--------------------------|
| 图像模型 | gpt-image-2（或环境中可用最强文生图模型） |
| 画面风格 | **阶段二必问确认项**（真人实拍/2D动画/3D动画/水墨国风/赛博科幻/复古胶片/漫画绘本/手绘插画等），全流程风格锚，禁止默认"写实" |
| 比例 | 16:9 或 9:16（按用户确认） |
| 分辨率 | 2K |
| 画质 | high |

## 完整流程总览

```
阶段一 获取剧本 → 阶段二 风格确认 → 阶段三 剧本分析与资产清单
→ 阶段四 色卡 → 阶段五 场景总调度图 → 阶段六 场景参考图
→ 阶段七 角色定妆三视图 → 阶段八 道具资产图
→ 阶段九 长视频分镜生成 → 阶段十 交付汇总
```

> 每个阶段结束都有 ⏸ 确认点，用户拍板才前进。

---

## 阶段一：获取剧本

1. 判断剧本来源：
   - **用户直接上传/粘贴剧本文本** → 直接读取
   - **用户指定工作区文档路径** → 读取该文档内容
   - **用户只给了主题/梗概** → 先记录，进入阶段二时一并确认
2. 若剧本缺失或不完整，先询问用户补充，**不要自行脑补整个剧本**
3. 报告：`📢 进度：剧本已获取（来源：上传/文档路径），共 X 字`

⏸ **确认点 1**：请用户确认剧本无误，或补充/修正。

---

## 阶段二：风格确认（用户确认核心环节）

拿到剧本后，**不要急着生成任何东西**，先询问用户以下偏好（逐项问，等用户回答）：

> **⚠️ 画面风格为第一询问项（V3 修复，禁止跳过）**：旧版此表缺少"画面风格"项，导致未询问即默认按"真人实拍/写实风格"执行，用户未选择却被定了风格——属严重 bug，已修复。画面风格未确认前，**禁止生成任何资产、禁止进入阶段三**。

| 询问项 | 选项示例 | 默认 |
|--------|---------|------|
| **画面风格** ⭐必问 | 真人实拍（写实电影）/ 2D动画（国漫/日漫/美漫）/ 3D动画（皮克斯式/写实CGI）/ 水墨国风 / 赛博科幻 / 复古胶片 / 漫画绘本 / 手绘插画 / 其他 | **必问，无默认**；仅当用户说"你看着办"才按题材推断并列出方案请确认 |
| 画幅 | 竖屏 9:16（短剧）/ 横屏 16:9（解说） | 9:16 |
| 色调基调 | 暖调/冷调/低饱和/高对比/复古/清新 | 按剧本题材推断 |
| 色卡偏好 | 用户指定的主色/强调色，或"你按剧本来定" | 按剧本推断 |
| 视频模型 | 即梦 Seedance / 可灵 / 环境可用模型 | 环境默认 |
| 单镜头时长偏好 | 5s / 8s / 10s | 8s |
| 目标视频总时长 | 2 分钟 / 3 分钟 / 更长 | 2 分钟 |

> 若用户说"你看着办"，则按剧本题材推断默认值，并**明确列出你选的方案（含画面风格）**请用户确认。
> **风格锚定（V3 新增）**：阶段二确认的"画面风格"成为全流程**风格锚**。此后所有模板（B 场景/C 场景/D 三视图/G 分镜）中的 `[画面风格]` 占位符一律填入此确认结果，禁止再默认写"写实风格"。

⏸ **确认点 2**：汇总风格方案（**画面风格必列**），请用户确认或调整。

---

## 阶段三：剧本分析与资产清单

1. 深度阅读剧本，提取：
   - **场景列表**：名称、类型（屋内/屋外）、时间（日/夜）、环境描述
   - **角色列表**：姓名、年龄、性别、外貌、服装风格、配饰。**提取范围（硬性规则）**：所有有名角色 + **所有有明确动作/台词/反应戏份的无名角色**（如"民兵""村民甲""货郎"等，即使无名只要有出场动作就必须列入）；纯背景无戏份的群像可合并为一个"群像资产"
   - **道具列表**：所有关键道具及描述
   - **角色动线**：每个角色的运动轨迹（起点 → 途经场景 → 终点）
   - **色彩基调**：按阶段二确认的风格，落到具体场景

2. 输出资产清单（固定格式）：

```
📋 资产清单

【场景表】
| 序号 | 场景名称 | 类型(屋内/屋外) | 时间(日/夜) | 环境描述 |
|------|---------|---------------|------------|---------|
| 1    | ...     | ...           | ...        | ...     |

【角色表】
| 序号 | 角色名 | 年龄 | 性别 | 外貌特征 | 服装风格 | 配饰 |
|------|--------|------|------|---------|---------|------|
| 1    | ...    | ...  | ...  | ...      | ...      | ...  |

【道具表】
| 序号 | 道具名称 | 描述 | 出现场景 |
|------|---------|------|---------|
| 1    | ...     | ...  | ...     |

【角色动线】
| 角色 | 运动轨迹（起点→途经场景→终点） |
|------|------------------------------|
| 角色A | 场景1 → 场景3 → 场景2 |
```

3. 报告：`📢 进度：剧本分析完成，共识别 N 个场景、N 个角色、N 个道具`

⏸ **确认点 3**：请用户确认资产清单（有无遗漏角色/场景、有无错误描述），确认后进入下一步。

---

## 阶段四：色卡（整体色调 + 场景配色）

> 色卡是后续所有资产和视频的光影依据，必须先定。

1. 用【模板库 E】生成**全片色卡** 1 张（主色调/辅色调/强调色/肤色基调/各场景光源色温）
2. 为每个主场景生成**场景色卡**（该场景主色/辅色/点缀色/光源色温）
3. 报告：`📢 进度：全片色卡 + N 张场景色卡已生成`

⏸ **确认点 4**：请用户确认色调是否符合预期，不满意则按意见调整色卡后重新生成。

---

## 阶段五：场景总调度图

1. 用【模板库 A】生成 1 张场景总调度图，核心要素：
   - 鸟瞰/俯视视角，屋内/屋外分区
   - 场景间通道/门/路径连接
   - **角色运动轨迹**：不同颜色箭头/虚线，附图例
   - 每个区域标注场景名
2. 报告：`📢 进度：场景总调度图已生成`

⏸ **确认点 5**：请用户确认空间布局与角色动线是否正确。

---

## 阶段六：场景参考图

1. 逐场景生成参考图，按类型选模板：
   - 屋内 →【模板库 B】（陈设/家具/光源/材质/氛围）
   - 屋外 →【模板库 C】（自然/天气/光线/建筑外观/氛围）
2. 保存到 `/场景`，命名 `场景_序号_场景名称`
3. 报告：`📢 进度：N 个场景参考图已生成并保存到 /场景`

⏸ **确认点 6**：请用户确认场景图符合想象，不满意的场景单独重做。

---

## 阶段七：角色定妆三视图

1. 为每个有戏份的角色生成定妆三视图，用【模板库 D】，**按戏份分级生成（硬性规则）**：
   - **主要角色**（有台词/贯穿剧情）：每个单独生成，命名 `角色_序号_角色名`
   - **次要角色**（无台词但有明确动作/反应，如民兵、村民甲）：每个单独生成（有名字按名字，无名按身份命名如 `角色_民兵`），出场段落必须 @引用
   - **纯背景群像**（仅围观无戏份）：可合并生成 1 张群像资产（如 `群像_村民`），或省略但必须在对应段落提示词中文字设定
   - **禁止**：有戏份的角色未生成资产、却在段落提示词里无引用且无文字设定
2. 逐角色生成，保存到 `/角色`，命名 `角色_序号_角色名`（次要角色按身份命名如 `角色_民兵`）
3. 报告：`📢 进度：N 个角色定妆三视图已生成并保存到 /角色`

⏸ **确认点 7**：请用户确认角色形象，不满意则按意见调整后重生成该角色。

---

## 阶段八：道具资产图

1. 为每个关键道具生成资产图，用【模板库 F】：
   - 居中单独展示、简洁纯色背景、材质细节清晰、最佳展示角度
2. 逐道具生成，保存到 `/道具`，命名 `道具_序号_道具名称`
3. 报告：`📢 进度：N 个道具资产图已生成并保存到 /道具`

⏸ **确认点 8**：请用户确认道具图，通过后进入分镜阶段。

## 阶段九：长视频分镜生成（2分钟+）

### 9.0 资产完整性检查（硬性门槛，未通过不得拆镜头）

进入分镜前，对照**阶段三资产清单**逐项核对（LibTV 模式下核对画布节点，标准模式下核对已交付提示词清单）：

```
📋 资产完整性检查表
| 类型   | 清单项 | 资产状态 | 缺失处理 |
|--------|--------|---------|---------|
| 色卡   | 全片色卡 | ✅/❌    | 缺则补生成 |
| 角色   | 每个角色（含次要角色/群像） | ✅/❌ | 缺则补生成或用户确认文字设定 |
| 道具   | 每个关键道具 | ✅/❌ | 缺则补生成或用户确认文字设定 |
| 场景   | 每个场景参考图 | ✅/❌ | 缺则补生成或用户确认文字设定 |
```

**规则（硬性）：**
1. 所有清单项资产必须**逐项列出检查结果**展示给用户
2. 缺失项：**优先补生成**；只有用户明确说"该项用文字设定"才允许跳过
3. 跳过项必须在该段落提示词的【基础设定】中**文字设定**（外貌/材质/特征），禁止凭空出现无设定资产
4. 检查通过后输出确认，再进入 9.1 拆镜头

### 9.1 先确认时长目标

按阶段二确认的目标时长执行；若未确认，此时询问用户目标视频时长。

### 9.2 时长换算（先算镜头数量）

| 目标总时长 | 单镜头 5s | 单镜头 8s | 单镜头 10s | 单镜头 15s |
|-----------|----------|----------|-----------|-----------|
| 2 分钟（120s） | 24 镜 | 15 镜 | 12 镜 | 8 镜 |
| 3 分钟（180s） | 36 镜 | 23 镜 | 18 镜 | 12 镜 |
| 5 分钟（300s） | 60 镜 | 38 镜 | 30 镜 | 20 镜 |

> 情绪戏/对话戏用 5-8s，动作戏/大场面用 10-15s，混合使用保证节奏。

### 9.3 四段结构拆解（比例 15% / 55% / 20% / 10%）

| 段落 | 占时 | 镜头作用 |
|------|------|---------|
| 开场钩子 | ~15% | 强冲突/强反差，3 秒勾住观众 |
| 发展推进 | ~55% | 冲突升级、人物互动、埋细节 |
| 高潮爆发 | ~20% | 情绪顶点、关键转折、金句 |
| 收尾悬念 | ~10% | 留下钩子 |

### 9.4 逐镜头提示词（用前面资产做一致性锚定）

每个镜头按六要素组装：

```
[景别 + 运镜]。[角色锚中的角色]在[场景锚中的场景]中[单一动作]，[环境细节]，[光影色彩（引用色卡）]，[质感氛围]，[情绪基调]。
```

- **一致性锚定**：角色锚（阶段七定妆图的服装/发型/道具特征）、场景锚（阶段六场景图的环境特征）、风格锚（阶段四色卡 + 阶段二确认的**画面风格**）**必须出现在每条提示词里**
- **六要素规则**：一段只写一种主运镜；一个动作最多两个连贯；禁复杂手势特写；禁抽象词；禁文字/字幕入画
- **转场标注**：硬切（默认）/ 淡入淡出 FADE（时间地点切换）/ 叠化 DISSOLVE（情绪过渡）/ 快切 CUT FAST（紧张节奏）

### 9.5 输出镜头清单（固定格式）

| 镜号 | 时长 | 段落 | 景别/运镜 | 画面内容 | 完整提示词 | 转场 |
|------|------|------|-----------|---------|-----------|------|
| 01 | 8s | 开场钩子 | 近景/推 | ... | （完整提示词） | 硬切 |
| … | | | | | | |

同时给出：参数建议（画幅/分辨率/运动幅度）+ 生成顺序（按镜号，定妆图/场景图作首帧）

> 💡 可选增强：镜头清单确定后，可用 `scripts/gen_shot_prompts.py` 批量导出/规范化提示词（详见脚本头部注释）。纯手工输出同样合格。

⏸ **确认点 9**：请用户确认镜头清单（数量/节奏/提示词质量），按意见调整后定稿。

## LibTV 画布模式（可选增强）

当环境中存在 **libtv CLI**（执行 `libtv --version` 可运行）时，本技能的图片/视频生成可直接落地到 **LibTV 画布**，替代"纯输出提示词"模式。执行前先确认前置：

1. **已登录**：`libtv login web`（浏览器授权）或 `libtv login phone`（手机验证码）
2. **已建画布**：`libtv workspace use <项目ID>`（定项目）→ `libtv project create <画布名>` → `libtv project use <画布UUID>`（定当前画布）
3. **查可用模型**：`libtv model search --type image` / `--type video` / `--type script`

各阶段落地对照：

| 阶段 | 标准模式（纯提示词） | LibTV 模式（libtv 命令，默认模型 **Lib Image**） |
|------|---------------------|----------------------------------------------------|
| 四 色卡 | 模板库 E 出提示词 | `libtv node create "色卡_全片" -t image --prompt "<模板E提示词>" -s "model=Lib Image" -s ratio=16:9 -s quality=high -s resolution=2K` → `libtv node "色卡_全片" --run` |
| 五 总调度图 | 模板库 A | 同上，节点名 `总调度图`；推荐加 `-s ratio=16:9` |
| 六 场景参考图 | 模板库 B/C | 每场景一个 image 节点，命名 `场景_序号_名称` |
| 七 角色三视图 | 模板库 D | 每角色一个 image 节点，命名 `角色_序号_名称` |
| 八 道具图 | 模板库 F | 每道具一个 image 节点，命名 `道具_序号_名称` |
| 九 分镜 | 输出镜头清单 | ① `libtv node create "剧本" -t script --prompt "<剧本全文>"` → `libtv node "剧本" --run` 生成分镜行；② 每段落一个 video 节点，prompt 用**模板库 G 四段式专业分镜格式**（基础设定/全局设定/画面内容/负面约束），角色图+色卡用 `{{Node "节点名"}}` 引用；③ 全部节点连线完毕后统一切 `image2video` 再逐镜 `--run` |
| 下载产物 | 用户自行保存 | `libtv download -n <节点名>` 拉回本地，按 `/场景` `/角色` `/道具` 归档 |

**LibTV 模式要点：**
- **默认推荐模型 —— Lib Image**（`lib-image-2`）：最新生图模型，长文本能力强、复杂版面与文字排版准确，对**色卡/总调度图/三视图**等需要标注文字的资产最合适；色卡示例已验证比 General image Pro 排版更专业、可直接用
- **Lib Image 参数差异**（其他模型可能不同，写脚本前先 `libtv model <modelKey>` 查 schema）：
  - `quality` 字段取值 `low / medium / high`（**不是** `1K/2K/4K`）
  - 分辨率用独立字段 `resolution=2K`（不是 `quality=2K`）
  - 示例：`-s "model=Lib Image" -s ratio=16:9 -s quality=high -s resolution=2K`
- **模型替换**：用 `libtv model search --type <类型>` 查当前画布可用模型；场景、角色、道具等纯画面资产也可切 `General image Pro`（一致性更好）或 `Seedream 4.5`（中式风格）
- 节点统一命名（`场景_序号_名称` 等），与资产目录归档规则一致，方便 `libtv download` 后对号入座
- **最终交付走网页端（重要）**：CLI 生成通道未继承网页端"去水印"权益，`libtv download` 拉回本地的图带平台水印。因此 **`libtv download` 仅为本地快速预览/归档的可选步骤**；正式交付资产一律在网页端画布打开对应节点下载（无水印）。网页端路径：登录 www.liblib.tv → 我的创作/画布 → 打开本画布 → 逐节点下载
- 分镜图组、视频节点生成后仍在画布上，如需本地预览再 `libtv download`
- **无 libtv 环境自动回退标准模式**，两条路径产出的提示词内容一致，只是落地方式不同
