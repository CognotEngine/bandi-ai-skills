## 模板库 A：场景总调度图（阶段五）

**用途**：生成 1 张含角色运动轨迹的全景调度图。

```
俯视鸟瞰图，[剧名] 全部场景空间调度图。屋内区域与屋外区域清晰分区，[场景1名][场景2名][场景3名]按空间关系排布，场景之间以门/通道/路径连接。[角色A]运动轨迹用[颜色A]虚线箭头标注：起点[场景X]→[场景Y]→[场景Z]；[角色B]运动轨迹用[颜色B]虚线箭头标注：[起点→终点]。每个场景区域标注名称，箭头带角色名图例，信息清晰可读的影视场景调度示意图，2K细节。
```

**占位符说明**：
- `[场景1名]...`：阶段三场景表的所有场景
- `[角色A]/[颜色A]`：阶段三角色动线表中每个角色配一个专属颜色

## 模板库 E：色卡（阶段四）—— 电影美术设定级方法论（V3 升级）

**用途**：生成 1 张**专业电影美术设定级**色卡。全片 1 张 + 每个主场景 1 张（场景色卡可在主色基础上替换具体环境色）。
**风格**：纯 2D 扁平化数字图形设计，类电影美术圣经/色彩系统说明页/视觉开发参考表/设计系统文档。
**必含三元素**：① 顶部标题区 ② 中部色块区 ③ 色块下方两行小字（HEX + 功能标签）。
**画幅**：16:9（横版排版最稳）。无主色卡可考虑 9:16。

```
一张干净的数字色卡参考设计图，16:9 横向构图，纯平面设计美学，没有任何摄影元素。
背景为纯色中性浅色填充，颜色根据主题整体气质选择（优先米白/灰白/暖白/冷白的低饱和背景色），背景必须完全平面化，无纹理、无阴影、无纸张质感、无桌面、无表面材质。

画面只包含以下三个部分：

【元素 1-顶部居中的标题文字】
使用干净的无衬线字体。主标题为近黑色，格式：「[项目名]·[场景/集数/主题]·[色彩系统名]」，有电影美术设定/世界观设定/视觉开发文档感。
主标题下方有一行更小的浅灰色副标题（无衬线字体），格式：「[环境氛围描述]·[N] color system」。

【元素 2-画面中部一排横向排列的 [N] 个矩形色块（默认 13，按场景复杂度 10~15）】
所有色块必须在同一水平线上，均匀间距，垂直居中。
每个色块都是干净的纯色矩形，尺寸完全一致，边缘锐利清晰。
色块不能有渐变、阴影、描边、纹理、光泽、厚度、透视或任何立体效果。
色块顺序从左到右形成清晰的色彩逻辑：
  先放置环境主色与光照色 → 再放置中间调与阴影色 → 再放置材质色 → 最后放置强调色或特殊功能色。

【元素 3-每个色块下方的两行小字】
第一行是对应 HEX 色值（等宽字体，深灰色）。
第二行是该颜色的功能标签（更小无衬线字体，中灰色）。功能标签按参考图中的颜色角色命名（不写颜色名而写它在画面中的作用），例如：「天空雾色」「暖光照射」「夕阳镀金」「麦浪中间调」「尘土中间调」「树荫暗部」「冷色反光」「阴影深处」「布料色」「金属高光」「肤色中间调」「血色强调」「夜暮收尾」等。

【占位符】
- [项目名] / [场景/集数/主题] / [色彩系统名]：当前项目标识
- [环境氛围描述]：4~8 字概括氛围
- [N]：默认 13；超过 15 拆成两排或分组；少于此影响专业度
- [HEX 色值] 与功能标签：按剧本氛围与已确认的色卡偏好，从参考图/预设色板填充

【整体视觉要求（必含约束）】
这是一张纯 2D 扁平化数字图形设计，不是照片、不是实物色卡、不是纸张印刷品、不是桌面摆拍。
风格精确、冷静、信息化、极简、专业；像电影美术圣经、色彩系统说明页、视觉开发参考表或设计系统文档。
构图清晰、整齐、克制，强调色彩信息本身。

【必须避免】
摄影、影渲染、纸张纹理、桌面、阴影、景深、镜头虚化、胶片颗粒、写实材质、3D 渲染、色块上的光照效果、色块下方阴影、光泽表面、手绘感、水彩感、插画感、草图感、实物 mockup、真实世界物体模拟。

【完成度自检清单（生成后核对）】
- [ ] 主标题三段式（项目·场景·色彩系统）准确
- [ ] 副标题含氛围描述 + 颜色数量
- [ ] 13 色横排、均匀间距、纯色矩形、零立体效果
- [ ] 色彩逻辑顺序：光照→中间调→材质→强调
- [ ] 每色块下方 HEX（深灰等宽）与功能标签（中灰无衬线），均按角色命名
- [ ] 整体扁平化、零摄影感、零纹理感
```

### 写作规则（硬性）

1. **占位符只引用实际存在的资产节点**：`{{Node "节点名"}}`（CLI 语法）；**无资产的角色/道具一律文字设定，禁止造假占位符**。**引用写完后必须立即读回验证**（CLI 对引用有不可靠丢弃行为）
2. **【画面内容】五要素必填**：镜头参数 / 机位 / 构图 / 光影 / 镜头运动，缺一不可（V2 要求）
3. **【画面内容】秒级分解**：每段 = 人物动作 + 表情 + 环境反应；秒数相加 ≤ 节点 duration（默认 15s）
4. **【负面约束】八组完整版**：角色一致性 / 动作物理 / 空间机位 / 场景环境 / 画质 / 风格 / 特效 / 杂项，逐字保留，可追加场景专属禁止项
5. **modeType 规则**：video 节点连了参考图必须 `image2video`；创建时先默认 `text2video` 建节点、连线，连完线后再 `-s modeType=image2video --prompt '...'` 一并更新（否则报"已连接媒体输入，无法使用纯文生视频"）
6. **引用建议直接用 nodeKey**（`{{Node <完整nodeKey>}}`）：比名字形式更稳，绕开同名/解析问题
7. **机位与运镜：按镜头功能选择（决策表，禁止一刀切）**。机位/运镜是镜头语言，**必须随剧情功能变化**，同一个剧本里应混合使用多种机位运镜与写法，制造节奏：

   | 镜头功能 | 机位建议 | 运镜建议 |
   |---------|---------|---------|
   | 情绪特写 / 内心戏 | 主观视角（模拟角色第一视角）或贴近特写 | 状态化（模拟角色感受：晃动/迟滞/屏息） |
   | 对话交锋 / 人物互动 | 客观正反打（机位在对话双方之间切换） | 固定 + 微推（情绪升温时） |
   | 动作 / 追逐 / 冲突 | 跟随机位（模拟奔跑/追赶）或客观 | 时间轴分秒式（0-X秒推近，X-Y秒高速跟拍） |
   | 环境交代 / 大场面 | 全景 / 高机位俯瞰 | 缓推或缓拉（展示空间） |
   | 悬念 / 停顿 / 收尾 | 客观机位 | 固定 + 缓慢拉远（留白） |
   | 道具 / 关键物件 | 特写，贴近物体 | 模拟物体状态（坠落/悬浮/静止凝视） |

   **机位两种写法**（按镜头功能选，同一集混合）：
   - 主观式：`模拟<角色/物体>的<第一/主观>视角`（情绪/道具/动作镜头）
   - 客观式：`摄影机位于<位置>，朝向<对象>拍摄`（对话/环境/收尾镜头）

   **运镜三种写法**（按镜头节奏需求选，同一集混合）：
   - 状态化单运镜：`模拟<状态/质感>的<运镜>`（如"模拟奄奄一息的晃动"——情绪镜头）
   - 时间轴分秒式：`0-X秒<运镜A>；X-Y秒<运镜B>；Y-Z秒<运镜C>`（如"0-2秒缓慢推近同时环绕；2-6秒高速跟拍；6-7秒轻微前推"——动作/复合运镜镜头）
   - 简单功能式：`固定 / 缓推 / 缓拉 / 跟拍`（对话/环境/收尾镜头）

   **原则**：一段视频节点内运镜可分段组合（时间轴分秒式天然支持多段运镜），但**严禁所有镜头同一种机位同一种运镜**，必须按上表混合。

   **【镜头语言五要素 · 从分镜内容智能推导（最高原则，禁止套模板）】**
   先读懂"这段分镜在讲什么"，再逐项推导，每个镜头都是为该段内容定制的：
   1. **镜头（类型+焦段）** ← 该镜头功能：建立镜头=超广角(24mm)；全景=28-35mm；中景=50mm；近景/特写=85-100mm；动作特写=100mm+
   2. **机位（可带轨迹）** ← 人物空间关系与视角：高位俯视/平视/仰视/低机位；可写变化轨迹（如"高位俯视，缓慢下降至平视"）
   3. **构图（含空间关系+美学意图）** ← 画面中谁与谁的位置关系 + 想传达的感觉（如"中央构图，主角居中，敌方呈扇形包围；大量留白体现荒野空间"）
   4. **光影（分层描述）** ← 场景时间光源+人物状态：主光+介质+轮廓光+局部点光（如"冷白月光主光，地面淡薄雾气，人物边缘银蓝轮廓光，敌方眼部暖黄色点光"）
   5. **镜头运动** ← 画面内容节奏：建立镜头=无人机式俯降/推进；情绪=状态化；冲突=高速跟拍；对话=固定微推
   【画面内容】写法层次：**先环境 → 再主角 → 再群体/互动**（如"月夜遗迹，风卷积雪。主角双手负后侧身而立，长袍轻扬。三只狼妖从三个方向包围，低伏蓄势，形成压迫感"）
   自检：写出五要素后对照分镜内容问一句"这个镜头是为这段内容量身定做的吗？换任何一段内容都能用吗？"——若换成别的也成立，说明没定制，重写。
